# LibreTV 综合推荐增强版

本分支新增综合热门推荐、滚动加载，以及基于观看历史的相似作品推荐。

原项目介绍与基础使用说明：[LibreSpark/LibreTV](https://github.com/LibreSpark/LibreTV)。

## 本分支的修改

- **热门推荐分类**：在首页“影视热榜”最前面新增“热门推荐”，默认选中。
- **综合内容**：首屏按豆瓣实时热门榜排序；后续混合热门电影、剧集、综艺和动漫，保留各榜单内部的顺序。
- **无限滚动**：接近页面底部时自动加载下一批，支持手动加载、失败重试；内容耗尽时显示结束提示。
- **相似推荐**：根据近期观看时长、观看比例和追剧进度选择作品，精确匹配豆瓣条目后补充相似作品。
- **过滤与去重**：过滤实际看过的作品，按作品 ID 和片名去除重复推荐。

## 使用说明

在设置中开启首页推荐，将推荐来源选择为“影视热榜”，然后进入“热门推荐”。点击海报可搜索现有片源。

观看历史保存在当前浏览器，不自动跨设备同步。没有观看历史时展示综合热门内容。不同榜单之间采用交错合并，不具有统一的跨榜单热度排名；滚动加载的数量取决于上游可提供的内容。

本分支功能需要从分支源码构建，原项目发布的镜像不包含这些修改。
