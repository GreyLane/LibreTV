# 综合热门推荐与滚动加载

本分支基于 LibreSpark/LibreTV `v2.16.12`，在首页“影视热榜”的分类最前面添加“热门推荐”，默认选中。

## 推荐行为

- 首屏使用豆瓣实时热门书影音榜中的影视条目，按上游热度排名展示。
- 后续分页混合热门电影、剧集、综艺和动漫榜单，保留每个榜单内部的排名。跨榜单采用交错合并，不声称这些榜单具有统一的可比较热度数值。
- 滚动接近页面底部时自动请求下一页，也提供手动“加载更多”作为补充。
- 根据当前浏览器的观看历史挑选最多八部种子作品；近期观看、观看比例和追剧进度影响权重。观看不足一分钟且没有后续集进度的记录不作为种子。
- 通过片名精确匹配豆瓣条目，再读取该作品的相似推荐。匹配失败时不使用错误作品兜底。
- 按作品 ID 和归一化片名去重，并过滤实际观看过的作品。
- 数据加载失败时保留已有内容并允许重试；所有数据源耗尽后显示结束提示，不重复内容制造无限列表。

## 数据与边界

观看历史仍保存在当前浏览器的 IndexedDB，不新增账户同步或历史数据库。请求推荐时会将最多八个种子片名发送给本部署的服务端，服务端再查询豆瓣。跨设备的历史不会自动合并。

豆瓣公开接口可能限流或变更；热门不代表所有片源均可播放，点击卡片仍走原有的搜索逻辑。推荐接口沿用现有登录保护和安全上游请求工具。
